# v9 개선 및 검증 기록

- 메인: 상단 로고 홈 이동, 시험 방법/기록 대시보드/시료 목록 메뉴
- 시험별 원본 SVG 아이콘, 자동 슬라이드, 클릭 시 시험별 입력 화면 이동
- 가상 예제 채우기: 액성·소성한계 원자료 입력으로 이동하고 예제값 자동 입력
- 시료별 통합 분석: 브라우저에 저장된 동일 시료의 시험 결과와 그래프를 하나의 페이지에 표시
- 서버 저장 기록 불러오기: SQLite 기록을 시료명 기준으로 묶어 브라우저에 통합
- 연구실 원본 XLS/XLSX, 실제 사진, 시료번호, 기관 정보, API 키를 포함하지 않음

## 주의 및 남은 검증
- 계산은 기존 교육용 Python 모듈에 기반하며 모든 공인 규격을 완전히 인증한 것은 아님
- 시료별 결과의 기본 보관은 현재 브라우저 localStorage이며, 다른 브라우저와 자동 동기화되지 않음
- 저장 기록 API는 키 기반 접근이며 정식 로그인/접근통제가 아님. 실제 비공개 연구실 데이터의 공개 서버 업로드 금지
- 자동 테스트는 서버 응답, Python 계산, 파일 구문을 점검. 브라우저 E2E는 실행 환경의 localhost 접근 제한으로 검증하지 못했으므로 실제 Mac Safari/Chrome에서 검증 필요
- 과제 필수 요건인 외부 배포, 실사용자 5명 테스트, 피드백 반영은 사용자가 수행해야 함
