## 비포함 범위
시료 채취 자동화, 이미지 기반 입도 인식, 수리전도도 실측, Casagrande 선행압밀압력 자동 산정, 압밀계수 Cv 자동 산정, 공인 시험 성적서 발행, 네이티브 APK/IPA 배포.

## API 계약
- `GET /api/health` → 서비스 상태
- `POST /api/analyze` → `{task: "grain|compaction|consolidation|water", payload: {...}, question?: "..."}`
- `POST /api/feedback` → `{rating: 1..5, comment: "...", task: "grain"}`
- `GET /api/feedback/stats` → `{count, average_rating}`

## 정확성 검토 기준
1. 입도 통과율은 입경이 감소하면 같거나 감소해야 한다.
2. D10/30/60은 측정 데이터 구간에서만 로그 보간한다.
3. 분류 필수 입력이 없으면 '미확정'으로 표시한다.
4. 5~12% 세립분은 이중 기호 후보를 검토한다.
5. 유기질 및 복잡한 경계 분류는 전문 검토가 필요하다.
6. 다짐 최적함수비는 측정 최고점과 곡선 피팅값을 구별한다.
7. 압밀 계산은 초기 높이·초기간극비 조건을 기록한다.
