# v6 UI/UX 개편 및 검증

## 개선 배경
기존 대시보드는 저장 건수와 시험 목록 위주로 구성되어 개별 시료의 결과를 비교하거나 그래프를 보는 데 불편했다.

## v6 개선
- 시료별 카드, 시험 유형별 막대그래프, 최근 7일 활동 그래프
- 시험 유형 필터와 시료명 검색
- 저장된 시험 상세 조회: 핵심 수치, 측정 그래프, 한글 공학적 해석
- 빈 데이터 상태에 대한 시작 안내
- 가독성 향상을 위한 밝은 배경, 높은 명도 대비, 반응형 카드
- 기존 원자료 계산/저장 API 유지

## 시험 순서
사용자 인터페이스 권장 흐름: 함수비 → 액성·소성한계 → 입도분석 → 다짐 → 강도(직접전단/일축압축) → 압밀 → 액상화 기초. 이는 편의상 배열이며 모든 시료에 적용되는 공식 시험 순서가 아니다.

## 개인정보 및 실험자료
사용자가 제공한 XLS/XLSX 및 이미지의 실제 수치·기관명·시료번호는 프로젝트 소스에 포함하지 않았다. 로컬 저장과 외부 배포의 저장소 보존 방식이 다르므로 서버 영구 볼륨/접근 제어를 별도로 설계해야 한다.

## 실제 시험과 설계의 경계
결과 대시보드는 측정값을 시각화하는 교육용 보조 도구이며 시험규격 적합성·지반 설계 안전성을 자동으로 보증하지 않는다.

## 검증 절차
1. pytest 전체 테스트
2. JavaScript 구문 검사
3. FastAPI /dashboard, /lab, /methods, /api/health 응답
4. 저장 후 /dashboard 그래프·상세조회·검색 확인
5. Safari/Chrome, 모바일 기기 수동 확인
