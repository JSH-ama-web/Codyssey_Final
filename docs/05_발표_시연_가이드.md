# 발표·시연 가이드 (약 8~10분)

1. 문제 제기 (45초): 실험 수치 계산/분류/보고서의 반복 문제
2. 사용자와 요구사항 (45초): 실험 수강생, 검증과 보고서 작성
3. 시스템 아키텍처 (60초): PWA → FastAPI → Python → RAG → LLM
4. AI 기술 선정 근거 (60초): Python 계산과 LLM 설명의 역할 분리
5. 실제 시연 (2~3분): 입도 예제 → 그래프 → USCS → 보고서 → 모바일
6. 오류 검증 (45초): 잘못된 통과율 입력 및 오류 처리
7. 사용자 테스트 (60초): 실제 5명 결과를 기록한 뒤 발표
8. 개선 및 한계 (60초): 유기질/경계 판정, 영구 DB, 공인 시험 아님
9. 팀 역할·회고 (30초): Git 커밋과 역할별 기여

**시연 전:** 배포 URL, 모바일 접속, AI 키, 인터넷, 보고서 다운로드, 예제 데이터, 브라우저 콘솔, 백업 동영상 확인.
