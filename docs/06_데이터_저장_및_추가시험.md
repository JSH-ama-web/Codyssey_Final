# GeoSoil AI v2: 시험 추가 및 저장 안내

## 지원 시험
- 입도분석/USCS 예비 분류, 다짐, 압밀, 함수비
- 직접전단: 최대전단응력-수직응력 회귀로 c와 φ 산정 (초기 면적 기준)
- 일축압축: 축변형률/보정단면적/압축응력 및 qu, 조건부 su≈qu/2
- 액성한계: Casagrande 다점법 25회에 대응하는 LL
- 소성한계: 반복 함수비의 평균 PL
- 액상화 반복하중 기초: Δu/σ′0로 ru와 반복횟수 곡선, 최초 ru≥1 측정점 표시. **CRR/CSR, 현장 액상화 위험도 판정은 하지 않음**

**주의:** 액성한계(liquid limit)와 액상화(liquefaction)는 서로 다른 시험입니다.

## 저장 방법
1. 시험 데이터를 입력하고 `분석 및 AI 보고서 생성`을 누릅니다.
2. 결과 화면의 `💾 데이터 저장`을 누르고 기록 이름을 입력합니다.
3. `내 시험 데이터 보관함`에서 불러오기/삭제/JSON 백업을 수행합니다.
4. 저장 데이터는 `DATABASE_PATH`가 지정하는 SQLite 파일에 보관됩니다. 로컬 기본값은 프로젝트 루트의 `geosoil.sqlite3`입니다.

## 저장 보안 및 배포
- 이 브라우저에 생성된 랜덤 소유 키를 통해 기록을 분리하는 **교육용 MVP**입니다. 계정 로그인/인증/접근권한 관리가 구현된 서비스가 아닙니다.
- 브라우저 저장소를 지우거나 다른 기기로 이동하면 기존 키를 잃을 수 있습니다. JSON 백업을 권장합니다. 백업 JSON에는 실험 데이터가 포함되므로 안전하게 보관하세요.
- 공유 PC에서는 기록을 저장하지 마세요. 개인정보/기밀 실험 데이터는 입력하지 마세요.
- Render 등 비영구 디스크에서는 서버 재시작/재배포 시 SQLite 기록이 사라질 수 있습니다. 영구 디스크와 `DATABASE_PATH` 또는 관리형 데이터베이스를 구성해야 합니다.
- 데이터 보관·접근제어·사용자 인증을 포함한 공개 상용 서비스는 별도 보안 설계가 필요합니다.
