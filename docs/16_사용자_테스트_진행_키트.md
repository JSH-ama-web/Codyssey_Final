# 16. 사용자 테스트 진행 키트

[04 사용자 테스트 계획 및 기록](04_사용자_테스트_및_피드백.md)을 진행할 때 그대로 복사해서 쓰는 자료.

## 1. 모집 메시지 (카카오톡용)

```
안녕! 내가 코디세이 최종 프로젝트로 토질시험 결과를 계산하고 AI가 해설해 주는 웹 서비스를 만들었는데, 실사용자 테스트를 부탁하고 싶어.

- 소요 시간: 15~20분
- 방법: 링크 접속 → 과제 5~6개 해보기 → 설문 응답
- 이름·학번은 수집 안 하고 익명 번호(T01~)로만 기록해
- 화면 캡처는 과제 증빙으로만 써

가능한 날짜/시간 알려주면 맞출게. 고마워!
```

## 2. 비대면 테스트 안내 메시지

```
테스트 도와줘서 고마워! 아래 순서대로 해 주면 돼. 막히면 억지로 해결하지 말고 막힌 지점을 그대로 알려줘. 그것도 중요한 결과야.

▶ 주소: https://no-one-can-know-the-soil.vercel.app
(공학적 해석은 AI가 만드는 데 10~15초 걸려)

S1. 홈 화면을 30초 둘러보고, 어떤 서비스 같은지 한 문장으로 적어줘.
S2. "＋ 새 시료 분석" → 시료 만들기 → 함수비 시험에서 "가상 예제 채우기" → "결과 계산하기"
S3. 같은 시료에서 액성·소성한계나 입도분석도 예제로 계산하고 그래프 확인
S4. 입력값 하나를 일부러 지우거나 이상한 값으로 바꿔서 계산 → 오류 메시지가 이해되는지
S5. "현재 결과 저장" → 상단 "시료 목록"에서 방금 시료 결과 모아 보기
S6. (가능하면) 스마트폰으로 접속해서 S2 다시 해보기

끝나면 아래 설문 부탁해!
설문: https://docs.google.com/forms/d/e/1FAIpQLSdOMt_Dj2YlArmlRvt7iaIZsbtgAUO-qI7Y8AtENLLbnipg6w/viewform
그리고 S2·S3 결과 화면 캡처 2장 보내주면 정말 고마워.
```

## 4. 대면 진행 대본 (진행자용)

1. 인사·동의 (1분): "익명 번호로만 기록하고, 화면 캡처는 과제 증빙으로만 써요. 괜찮아요?"
2. 원칙 안내 (30초): "서비스를 평가하는 거지 당신을 평가하는 게 아니에요. 생각나는 걸 소리 내서 말해 주세요. 제가 도와드리지 않을 거예요."
3. 과제 S1~S6을 하나씩 읽어 주고 관찰 기록지 작성
4. 설문 링크 전달 (3분)
5. 마무리 질문 (2분): "하나만 고친다면 뭘 고치고 싶어요?"

## 6. 테스트 후 정리 순서
1. 관찰 기록지 + 설문 결과를 [04 문서](04_사용자_테스트_및_피드백.md) 6번 기록표에 옮긴다.
2. 7번 결과 요약(성공률·평균 점수·공통 의견 상위 3개)을 작성한다.
3. 공통 의견 1~3개를 GitHub Issue로 등록한다 (`.github/ISSUE_TEMPLATE/feedback.md`).
4. 이슈마다 `fix/*` 브랜치 → PR(`Closes #번호`) → CI 통과 → 병합.
5. 해당 참여자에게 재확인 받고, 04 문서 8번 개선 기록과 전/후 화면을 채운다.
6. `docs/02` FR-13 상태를 "완료"로 변경한다.
