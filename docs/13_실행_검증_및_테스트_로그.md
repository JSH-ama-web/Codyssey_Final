# 13. 실행 검증 및 테스트 로그

> 항목: 기능 실행·에러 없음 증빙. 아래 로그는 실제 명령 실행 결과를 그대로 붙인 것이다.

## 1. 자동 검증 구성

| 단계 | 도구 | 실행 위치 | 명령 |
|---|---|---|---|
| 코드 스타일 | ruff format | 로컬·GitHub Actions | `ruff format --check app api tests` |
| 정적 분석 | ruff check (E, W, F, I, B, UP) | 로컬·GitHub Actions | `ruff check app api tests` |
| 단위·API 테스트 | pytest (45개) | 로컬·GitHub Actions | `pytest -v` |
| 배포 빌드 | Vercel (Python 서버리스) | push 시 자동 | Vercel → Deployments |
| 가동 확인 | GitHub Actions `uptime.yml` | 6시간마다 | `GET /api/health` |

GitHub Actions 결과: 저장소 → **Actions** 탭 → `CI (lint + test)` 실행 기록. 각 실행의 `test-report` 아티팩트에 `pytest.log`, `pytest-report.xml`이 저장된다.

## 2. 테스트 범위

| 파일 | 검증 내용 |
|---|---|
| test_engineering.py, test_raw_workflows.py, test_additional.py | 입도·다짐·압밀·전단·일축·액성/소성한계·액상화 계산값과 입력 오류 처리 |
| test_saved_records.py | 기록 저장·조회·삭제, 계산 결과 위변조 거부 |
| test_v5.py, test_v9_*.py, test_v13/v14_regression.py, test_studio_v7.py, test_dashboard_v6.py, test_methods_page.py | 페이지 라우팅, 정적 자산, 화면 회귀 |
| **test_v14_1_ops.py** | 코디세이 AI Gateway 호출(Anthropic 형식), 404 시 OpenAI 호환 형식 자동 전환, 키 없음·Gateway 장애 시 로컬 해설 전환, `/api/health` 비밀값 미노출, 모든 응답의 `X-Request-ID` |

AI Gateway 테스트는 실제 키를 쓰지 않고, 테스트 안에서 Gateway를 흉내 내는 로컬 HTTP 서버로 요청 경로·헤더·모델명을 검증한다.
