# v7 시료별 시험 결과 스튜디오

- 참고: 사용자 제공 화면 5장의 **정보 구조**(원자료 입력 → 결과 카드 → 그래프 → 계산 표 → 시료 통합 화면)를 참고하여 독립적인 UI를 구현함. 타 서비스의 코드·이미지·문구는 복사하지 않음.
- 차별화: 함수비 캔 원자료, 액성한계의 초기 건조/습윤 2캔 평균과 LL·PL 분리, 다짐점 2캔 평균, 현장 시공 전 검토와 해석 한계.
- 정확성: 모든 계산은 기존 Python 엔진 사용. 그래프는 원자료 기반이며 일부 단순 선 연결은 공인 곡선 피팅 또는 설계기준이 아님. LL은 계산 엔진에서 타격횟수 로그회귀로 25회 함수비 산정.
- 안전: 실제 지반 강도·투수성·압축성 및 안전율은 제한된 실험만으로 확정하지 않음.
- 보안: 업로드된 연구실 사진·XLS·XLSX 원본 및 실측 숫자는 배포 산출물에 포함하지 않음.
- 다음 검증: 실제 사용 브라우저 Safari/Chrome/모바일 조작, 5명 이상 사용자 피드백, ASTM/KS 적용 버전 확인, 배포 환경에서 데이터 지속성 검증.
