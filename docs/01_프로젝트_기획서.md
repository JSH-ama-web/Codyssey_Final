# 프로젝트 기획서 | GeoSoil AI

## 1. 프로젝트 개요
- 프로젝트명: GeoSoil AI, 스마트 토질시험 결과 분석 및 흙 분류 Agent
- 개발 유형: 5인 팀 AI Native 캡스톤, PC 웹 + 모바일 PWA
- 핵심 가치: 계산 재현성, 공학적 해석 보조, 보고서 작성 시간 절감

## 2. 문제 정의
대학 토질역학 실험에서 계산, 그래프, USCS 분류, 보고서 작성이 분절되어 있어 수기 입력 오류와 반복 노동이 발생한다. 초보자는 산출값의 의미와 적용 한계를 이해하기 어렵다.

## 3. 타겟 사용자
1차: 토목공학/지반공학 실험 수강생. 2차: 실험 조교 및 교육자. 현장 설계용은 대상에서 제외한다.

## 4. 사용자 시나리오
사용자가 실험 데이터를 입력 → 입력값의 단위/순서 오류 확인 → Python 계산 → 그래프/USCS 예비 분류 → AI 근거 해설 → HTML 보고서 다운로드 → 만족도 및 개선 의견 제출.

## 5. AI 활용 근거
LLM에 수치 계산을 직접 맡기면 환각 가능성이 있다. 계산은 결정론적 Python으로, 자연어 해석만 LLM으로 분리한다. 소규모 로컬 RAG로 해설 근거를 제한한다. 키 미설정/호출 실패 시 로컬 근거 해설을 제공한다.

## 6. 개발 일정 (예시 4주)
| 주차 | 목표 | 완료 기준 |
|---|---|---|
| 1주 | 요구사항·공학 공식·와이어프레임 | 기획/명세 검토 |
| 2주 | Python 계산·API·테스트 | pytest 통과 |
| 3주 | UI/PWA·AI/RAG·배포 | 모바일/PC 접속 |
| 4주 | 실사용자 5명 이상 평가·개선·발표 | 피드백 기록 및 변경 이력 |

## 7. 성과 지표
- 실제 테스트 사용자 5명 이상(필수)
- 정상 샘플 테스트 통과율 100% 목표
- 잘못된 입력에 422 오류와 사용자 메시지 제공
- 동일 데이터 반복 입력 시 결과 동일
- 사용자 만족도 평균 4.0/5.0 목표(미측정)
- 사용자 피드백에 따른 개선 커밋 1개 이상 목표

## 8. 위험과 대응
USCS 경계 및 유기질 판정 누락 위험: '미확정'과 경고 표시. 외부 API 장애: 로컬 해설로 전환. 배포 SQLite 데이터 유실: 영구 저장소 전환 또는 별도 기록. 키 유출: 환경변수 사용. 학생 데이터 민감성: 익명 입력만 수집.

## 9. 현재 상태
기본 기능 및 테스트 코드가 포함된 제출용 개발 패키지. 실제 사용자 5명 테스트, 공개 배포 URL, 피드백 개선 실적은 팀이 수행하고 기록해야 한다.
