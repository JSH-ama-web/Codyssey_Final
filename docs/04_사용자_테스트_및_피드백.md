# 04. 실사용자 테스트 계획 및 기록

**현재 상태: 1차 테스트 완료 (2026-11-23, 비대면 5명), 피드백 반영 PR 진행.** 아래 기록은 Google Forms 응답과 참여자가 보낸 화면 캡처를 그대로 옮긴 것이다.

- 서비스 주소: https://no-one-can-know-the-soil.vercel.app
- 설문(Google Forms): https://docs.google.com/forms/d/e/1FAIpQLSdOMt_Dj2YlArmlRvt7iaIZsbtgAUO-qI7Y8AtENLLbnipg6w/viewform
- 진행 키트(안내 메시지·설문 문항·관찰 기록지): [16_사용자_테스트_진행_키트.md](16_사용자_테스트_진행_키트.md)

## 1. 목적
1. 토질시험 수강생이 원자료 입력 → 계산 → 그래프 → AI 해설까지 도움 없이 완료할 수 있는지 확인한다.
2. 오류 메시지와 AI 해설이 실제로 이해에 도움이 되는지 확인한다.
3. PC·모바일 모두에서 사용 가능한지 확인한다.
4. 나온 문제를 GitHub Issue → PR로 개선하고 재확인한다.

## 2. 참여자
| 항목 | 기준 |
|---|---|
| 인원 | 5명 이상 (목표 6~7명) |
| 대상 | 토질역학 실험 수강(예정)생 4명 이상 + 비전공자 1명 이상 |
| 기기 | PC 2명 이상, 스마트폰 2명 이상 |
| 개인정보 | 이름·학번 미수집. T01~ 익명 번호만 사용. 화면 캡처 시 개인정보 가림 |
| 동의 | 시작 전 "익명 기록·화면 캡처 활용" 구두 또는 설문 첫 문항으로 동의 |

## 3. 진행 방식 (비대면)
- 참여자에게 안내 메시지(과제 S1~S6 + 서비스 주소 + 설문 링크)를 카카오톡으로 보낸다. 문구는 [16 진행 키트](16_사용자_테스트_진행_키트.md) 2번.
- 참여자는 혼자 과제를 수행한 뒤 Google Forms 설문에 응답하고, S2·S3 결과 화면 캡처 2장 이상을 보낸다.
- 진행자가 옆에서 관찰하지 않으므로 별도 관찰 기록지는 작성하지 않는다. 대신 아래 자료로 수행 결과를 판단한다.
  - 과제 수행 여부: 설문 "끝까지 해본 과제" 체크 항목
  - 막힌 곳·오류: 설문 "가장 불편했던 점이나 오류" 서술 답변
  - 실제 수행 증거: 참여자가 보낸 결과 화면 캡처
- 설문 답변이 모호하면 카카오톡으로 짧게 추가 질문하고, 그 답도 기록표 "주요 의견"에 함께 적는다.
- AI 해설은 생성에 10~15초가 걸린다는 점을 안내 메시지에 포함한다.

- **공통 의견 상위 3개**
