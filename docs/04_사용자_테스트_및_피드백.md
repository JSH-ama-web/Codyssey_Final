# 04. 실사용자 테스트 계획 및 기록

**현재 상태: 진행 전.** 아래 기록표는 실제 참여자의 테스트 결과로만 채운다. 결과를 임의로 작성하지 않는다.

- 서비스 주소: https://no-one-can-know-the-soil.vercel.app
- 설문(Google Forms): https://docs.google.com/forms/d/e/1FAIpQLSdOMt_Dj2YlArmlRvt7iaIZsbtgAUO-qI7Y8AtENLLbnipg6w/viewform
- 진행 키트(안내 메시지·설문 문항·관찰 기록지): [16_사용자_테스트_진행_키트.md](16_사용자_테스트_진행_키트.md)

## 1. 목적
1. 토질시험 수강생이 원자료 입력 → 계산 → 그래프 → AI 해설까지 도움 없이 완료할 수 있는지 확인한다.
2. 오류 메시지와 AI 해설이 실제로 이해에 도움이 되는지 확인한다.
3. PC·모바일 모두에서 사용 가능한지 확인한다.
4. 나온 문제를 GitHub Issue → PR로 개선하고 재확인한다.

## 2. 참여자
| 항목 | 기준 |
|---|---|
| 인원 | 5명 이상 (목표 6~7명) |
| 대상 | 토질역학 실험 수강(예정)생 4명 이상 + 비전공자 1명 이상 |
| 기기 | PC 2명 이상, 스마트폰 2명 이상 |
| 개인정보 | 이름·학번 미수집. T01~ 익명 번호만 사용. 화면 캡처 시 개인정보 가림 |
| 동의 | 시작 전 "익명 기록·화면 캡처 활용" 구두 또는 설문 첫 문항으로 동의 |

## 3. 진행 방식
- 대면(권장): 15~20분. 진행자는 과제만 읽어 주고 도와주지 않는다. 막혀서 도움을 준 경우 기록한다.
- 비대면: 안내 메시지와 과제를 보내고, 설문 응답 + 결과 화면 캡처 2장 이상을 받는다.
- AI 해설은 생성에 10~15초가 걸린다는 점을 미리 안내한다.

## 4. 테스트 과제
| # | 과제 (참여자에게 읽어 주는 문장) | 성공 기준 | 확인 화면 |
|---|---|---|---|
| S1 | 서비스에 접속해서 어떤 서비스인지 30초 동안 둘러봐 주세요. | 서비스 목적을 한 문장으로 말함 | 홈 `/` |
| S2 | "＋ 새 시료 분석"으로 시료를 하나 만들고, 함수비 시험에서 "가상 예제 채우기" 후 결과를 계산해 주세요. | 함수비 값과 공학적 해석(AI 해설)이 표시됨 | `/studio` |
| S3 | 같은 시료에서 액성·소성한계 또는 입도분석을 계산하고 그래프를 확인해 주세요. | 그래프와 LL·PL·PI 또는 USCS 분류가 보임 | `/studio` |
| S4 | 입력값 하나를 일부러 비우거나 말이 안 되는 값으로 바꿔서 계산해 주세요. | 오류 메시지를 보고 무엇을 고쳐야 하는지 말함 | `/studio` |
| S5 | "현재 결과 저장" 후 "시료 목록"에서 방금 시료의 결과를 모아 봐 주세요. | 한 시료에 여러 시험 결과가 묶여 보임 | `/samples` |
| S6 | 스마트폰으로 접속해서 S2를 다시 해 주세요. (PC 참여자는 생략 가능) | 모바일에서 입력·결과 확인 가능 | `/studio` |
