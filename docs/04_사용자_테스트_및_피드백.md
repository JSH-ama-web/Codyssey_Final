# 실사용자 테스트 계획 및 기록지

**현재 상태: 미진행. 실제 사용자 참여 기록을 임의로 작성하지 마세요.**

## 테스트 대상
토목공학 실험 수강생 또는 조교 최소 5명. 동의 후 익명으로 참여하고 학번/이름은 저장하지 않는다.

## 수행 시나리오
1. PC에서 입도분석 예제 불러오기 → USCS 결과 확인
2. 한 체의 통과율을 역전시켜 오류 메시지 확인
3. 다짐 시험 예제로 최대 건조밀도 확인
4. 스마트폰에서 접속하여 함수비 계산
5. HTML 보고서 다운로드 및 열기
6. AI 키 설정 환경에서 보고서 초안 확인
7. 1~5점 평가 및 개선 의견 제출

## 평가 설문
- 계산 결과를 이해하기 쉬웠나요? (1~5점)
- 입력 화면을 사용하기 쉬웠나요? (1~5점)
- 그래프가 도움이 되었나요? (1~5점)
- 보고서 초안이 도움이 되었나요? (1~5점)
- 불편했던 점 또는 오류는 무엇인가요? (자유서술)
- 추가로 필요한 기능은 무엇인가요? (자유서술)
